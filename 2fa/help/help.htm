2fa: Two-factor login for CMSimple_XH

After a correct admin password, CMSimple_XH asks for a 6-digit code from Google Authenticator before any admin page or action runs. Setup is done in the backend under Plugins → 2fa.

What it does

  • Setup in the backend: open Plugins → 2fa to set up two-factor authentication. The page shows a QR code and a setup key. Ten one-time backup codes are shown once right after setup.
  • Before setup is complete: a password login goes straight to Plugins → 2fa without a code prompt.
  • After setup: every admin login asks for a fresh 6-digit code after the password.
  • Replay and brute-force protection: each code can be used only once. Five wrong codes lock verification for 15 minutes.
  • Backup codes: each works once in place of the app code, for example if you lose your phone. Only their hashes are stored on the server.
  • Backend management: view the number of remaining backup codes, generate a new set, or reset the 2FA secret.
  • Access protection check (Plugins → Check for Access Protection): Checks the whole plugin folder for files that other users can write to, and tests whether data/, data/twofa.php are blocked from web access. It also reports file permissions and whether PHP can write to data/.
  • Languages: English, Dutch, and German, editable under Plugins → 2fa → Language.
  • Visitors: visitors who are not logged in see no change.

The plugin does not change any CMSimple_XH core files, so CMSimple_XH updates will not remove it.

Requirements

  • CMSimple_XH 1.8. Test on a staging copy before deploying to a live site.
  • PHP 7.1 or newer, with hash_hmac, random_bytes, and intdiv.
  • Apache, or Nginx (see addendum.txt).
  • A phone with Google Authenticator, or another TOTP app such as Aegis, FreeOTP, or Microsoft Authenticator.

Installation and setup

Do this right after installing. Until setup is complete, the admin password alone reaches the backend.

  1. Unzip the downloaded 2fa.zip and copy the 2fa folder into your CMSimple_XH plugins/ directory. The folder name must be exactly 2fa. Do not copy it to an Apache reverse proxy. The plugin must run on the server that runs CMSimple_XH's PHP.
  2. Log in to CMSimple_XH with your admin password. No code is asked yet.
  3. Go to Plugins → 2fa. The page shows Status: Not set up yet and the setup section.
  4. Scan the QR code with Google Authenticator (tap + and choose Scan a QR code). Or choose Enter a setup key and type the key shown below the code.
  5. Enter the 6-digit code the app shows and click Complete setup. Setup is not finished until this code is accepted.
  6. Save the 10 backup codes shown on the same page. They are displayed once. Print them or write them down.
  7. Test the setup:
    • Log out and log in again. The 2FA code prompt must appear.
    • A wrong code must be refused.
    • The same code must not work twice.
    • Optional: a backup code logs you in once and is then invalid.
Important: until step 5 is complete, anyone who knows the admin password can complete setup and set the key. Set up right after installing, and use a strong, unique admin password.

If the setup key expires, for example after a long pause, reload Plugins → 2fa and scan the new QR code.

Logging in

  1. Enter the admin password on the CMSimple_XH login form.
  2. Enter the 6-digit code from Google Authenticator, or one unused backup code.
  3. The admin area opens.

A new password login always needs a fresh code. Codes from the app change every 30 seconds.

Managing 2FA

Moving to a new phone

Use Google Authenticator's account transfer (Menu → Transfer accounts → Export accounts). Scan the transfer QR code with your new phone. Nothing changes on the website.

Regenerating backup codes

Go to Plugins → 2fa. Under Regenerate Backup Codes, enter a current 6-digit code. The old backup codes stop working immediately.

Resetting the 2FA secret

Go to Plugins → 2fa. Under Reset 2FA Secret, enter a current 6-digit code or an unused backup code. The secret and all backup codes are removed, and you are sent back to the setup page. To use more than one device, scan the same QR code on each device before completing setup.

Checking access protection

  1. Go to Plugins → Check for Access Protection. This opens the 2fa page and runs the check.
  2. Read the results. A check mark means the item is OK. A cross means it needs fixing. A question mark means the check could not be run from the server.
  3. Fix any problems using addendum.txt, then select Run check to test again.

The web-access tests only work on a live site. Run them on the site itself, not on a local copy.

Troubleshooting

Message or problemWhat to do
Could not save the two-factor data. Check that plugins/2fa/data is writable. The server does not allow PHP to write to data/. See addendum.txt for file permissions. Check the web server error log.
The setup key has expired. Reload Plugins → 2fa. A new QR code and setup key are created.
The QR code area is empty, or shows "QR code not shown". The file js/qrcode.js is missing or blocked. Re-upload the js/ folder. The setup key still works.
Too many failed attempts. Five wrong codes locked verification for 15 minutes. Wait, then try again with a fresh code.
The code is always refused. Turn on automatic network time on your phone. TOTP depends on accurate time.
A backup code is refused. Each backup code works once. Dashes and letter case are ignored. Failed attempts count toward the same lockout.
Login works without a code prompt. Setup is not complete. Finish it under Plugins → 2fa. Also check that the folder is named exactly 2fa and is not listed under plugins/disabled.
Locked out: lost phone, wrong key, and no backup codes. Connect by FTP, SFTP, or SSH and delete plugins/2fa/data/twofa.php. The next password login goes to the setup page. Have your phone ready, and finish setup right away.

Security notes

  • Keep data/ private. Anyone who can read data/twofa.php can generate valid codes.
  • Never publish, copy, or screenshot data/twofa.php, your setup key, or your backup codes.
  • Until setup is complete, the admin password alone reaches Plugins → 2fa. Complete setup right after installing.
  • This plugin does not protect against an attacker who already has server access.
  • Page-data saves run in the CMSimple_XH core before plugins load, so with only the admin password an attacker could save page data before the code prompt. Use a strong, unique admin password.
